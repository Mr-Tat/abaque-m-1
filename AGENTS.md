# GRAN-abaque-m-1

Ce dépôt est la source autonome de l’Abaque des longueurs. Développer le moteur, l’accueil et les règles de jeu ici. Mathas-Connect reçoit une copie d’un commit identifié, avec un manifeste d’empreintes ; ses adaptateurs Auth/serveur ne sont pas le moteur autonome.

Préserver les aides pédagogiques, les résultats existants et les clés de stockage lors d’un renommage. Les modes Master et simulation ne donnent aucun acquis réel. L’application autonome ne fait aucune écriture Connect.

Vérifier les parcours au clavier et le mode normal ainsi que le Laboratoire isolé. Les tests et la CI utilisent Node 22.22.0 et Playwright 1.57.0. Ne pas annoncer un déploiement ou une recette hébergée sur la seule base des tests locaux.
